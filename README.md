# macPaint

macOS 스타일의 단일 그림 앱. **PNG 편집기**(래스터, GIMP·JS Paint 기능, 기본 화면)와 **SVG 편집기**(벡터, 일러스트레이터식)를 한 창에서 쓴다. 외부 CDN·서버 없이 동작한다.

## 내려받기 (macOS)
[`downloads/macPaint.dmg`](downloads/macPaint.dmg) 를 열어 `macPaint.app`을 Applications로 끌어 놓는다. (Apple Silicon·Intel 공용, 임시 서명이라 처음 한 번은 **우클릭 → 열기**)
웹에서는 `npm start` 후 http://localhost:8766/ 를 연다.

## 시작 화면 · 새로 만들기
- 앱을 켜면 **시작 화면**이 열린다: 새 PNG 이미지 · 새 SVG 문서 · 파일 열기 · **최근 항목**(미리보기·크기·시간, 클릭하면 다시 열림, × 로 제거, "목록 지우기"). 상단 로고를 누르면 언제든 다시 열린다. 최근 항목은 파일을 열거나 저장할 때 기록되며 브라우저 저장소(IndexedDB)에 최대 12개 보관한다.
- **새로 만들기**(탭 줄의 **+**, 파일 메뉴, 시작 화면)는 GIMP처럼 템플릿을 고른다: 용지 A0~A7·B4·B5·B5-일본·US Letter/Legal(300ppi), 명함, CD 커버, 웹 배너·아이콘, 화면(XGA~8K), 휴대폰. 크기는 **픽셀 기준**이 기본이고 인치·밀리미터·포인트·파이카·센티미터·미터·피트·야드로 바꿔 입력할 수 있다. 가로/세로 전환과 해상도(ppi) 지정도 된다. PNG는 메모리 때문에 36메가픽셀을 넘으면 비율을 지켜 줄여 만든다(A2 300ppi까지 그대로).

## 문서 탭
두 편집기 모두 위쪽 탭 줄에서 여러 문서를 동시에 열어 둘 수 있다. **+** 새 탭 · 탭 더블클릭 이름 바꾸기 · **×**/휠클릭 닫기(변경이 있으면 확인). 탭마다 그림·실행 취소 기록이 따로이고, 저장 파일 이름은 탭 이름을 따른다. SVG의 "PNG 편집기로 보내기"는 PNG 쪽에 새 탭으로 열린다.

## SVG 편집기
- **원본 보존 열기**: SVG 파일의 마크업(CSS·마커·그라디언트·텍스트 정렬·변형)을 그대로 보존해 원본과 똑같이 열린다(스크립트·이벤트 속성은 제거). 개체를 눌러 GUI로 옮기고 키우고 돌리고 색을 바꾸며, **코드 탭**에서 전체 문서나 선택한 개체의 SVG 코드를 직접 고쳐 적용할 수 있다.
- **원본 SVG 편집**: 글자는 더블클릭(또는 문자 도구로 클릭)해서 제자리에서 고치고, 직각 연결선은 선택하면 가운데 꺾이는 구간에 막대 손잡이가 나타나 끌어서 위치를 조절한다.
- 도구: 선택(V) · 직접 선택(A) · 펜(P) · 사각형(M) · 타원(L) · 선(N) · 다각형(G) · 별(S) · 문자(T) · 스포이트(I) · 손(H) · 확대(Z)
- 선택 개체의 8방향 크기 조절(Shift 비율 고정, Alt 중심 기준)·회전(Shift 15° 단위), Alt+끌기 복제, 방향키 이동, 가두기 선택(마키)
- 펜: 클릭=모서리, 끌기=곡선 핸들, 시작점 클릭=닫기. 직접 선택으로 앵커·핸들 편집(더블클릭: 곡선↔모서리)
- 칠·선·두께·불투명도·끝/모서리·둥근 모서리, 정렬 6종 + 분배, 정돈(앞/뒤), 좌우·상하 뒤집기, 90° 회전, 그룹·해제
- 레이어(보이기·잠금·이름·순서), 아트보드 크기·배경, 되돌리기 200단계
- 열기: SVG(path 호·곡선, transform, g→레이어/그룹) · PNG/JPG(이미지 개체로 배치), 저장: SVG · PNG 내보내기 · **PNG 편집기로 보내기**

## PNG 편집기
- JS Paint의 도구 16종 + 그라디언트(선형·방사형), 선택·변형·텍스트(안티앨리어싱), 히스토리 트리
- GIMP식 **필터**: 밝기·대비, 색조·채도·명도, 흑백, 세피아, 색 반전, 임계값, 포스터화, 흐림, 선명하게, 픽셀화, 노이즈, 엠보스, 가장자리 검출, 비네팅 (선택 영역에만 적용, 슬라이더 미리보기)
- 허용 오차 채우기, 선택 영역으로 자르기, 이미지 크기 조정(쌍선형), 캔버스 크기
- 열기·드래그&드롭·클립보드 붙여넣기(PNG), PNG 저장

### 레이어 · 객체 (PNG 편집기)
오른쪽 **레이어 패널**에서 레이어를 쌓아 쓴다. 레이어마다 눈 아이콘(표시/숨김), 미리보기, 이름(더블클릭으로 변경), **불투명도**(끄는 동안 실시간 미리보기)가 있고, 새 레이어·복제·위/아래로·**아래와 병합**·삭제·**이미지 병합**(메뉴)을 지원한다. 모든 동작은 기록(되돌리기·기록 이동)에 들어간다.
- **객체 모드**(패널 오른쪽 위 체크): 켜면 연필·브러시·도형·직선·곡선·그라디언트·글자가 **새 레이어(객체)** 로 만들어져, 나중에 **이동 도구**(왼쪽 맨 위)로 클릭해 골라 옮길 수 있다. 꺼 두면 지금 고른 레이어에 그린다.
- **붙여넣기·이미지를 레이어로 열기…** 는 항상 객체로 올라온다(캔버스보다 크면 맞춰 줄임). 붙여넣으면 이동 도구가 선택된다.
- 지우개는 배경 레이어에서는 배경색으로, 위 레이어에서는 투명하게 지운다. 이미지 크기 조정·자르기·뒤집기·회전은 모든 레이어에 같이 적용된다.
- 한계: 레이어는 캔버스 크기와 같아서, 객체를 캔버스 밖으로 밀면 밖으로 나간 부분은 잘린다(되돌리기로 복구).

## 개발
```bash
npm test                   # node --test (Node 20+)
npm start                  # 웹으로 실행
./tools/build_dmg.sh       # macPaint.app → downloads/macPaint.dmg (Xcode 명령행 도구 필요)
```
구조: `src/`(래스터 엔진: 연산 기록·히스토리 트리) · `src/svg/`(벡터 모델·파서·편집기) · `macos/main.swift`(WKWebView 셸) · `tools/`
